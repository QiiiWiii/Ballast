# Ballast 品牌与界面规范

## 快速参考

- 品牌概念：压舱、平衡、可审计的执行控制。
- 视觉方向：日间舰桥。深色控制平面配冷白数据工作区，不模拟消费级交易所的霓虹终端。
- 标志性元素：水平载荷线、中央龙骨、黄铜压舱块，以及产品中的居中稳定轴。
- 品牌语气：克制、准确、可核验。说明状态和下一步，不使用夸张收益承诺。

## Logo

Logo 由四个有业务含义的形状构成：水平线表示载荷与目标平衡，两侧载荷块表示需要被调度的执行量，中央竖线表示龙骨和业务事实源，底部黄铜块表示使系统恢复稳定的“压舱石”。该几何结构与控制舱、任务详情中的稳定轴共用视觉语法。

正式资产：

- `web/public/ballast-logo.svg`：浅色背景横向主标志。
- `web/public/ballast-logo-reversed.svg`：深色背景横向反白标志。
- `web/public/ballast-mark.svg`：独立标志，适用于应用入口和方形空间。
- `web/public/favicon.svg`：浏览器小尺寸版本。

横向标志最小宽度为 160px，独立标志的界面最小尺寸为 32px，favicon 可缩至 16px。标志四周至少保留一个压舱块高度的净空。禁止拉伸、旋转、重排、添加阴影或渐变，也禁止替换为交易所品牌色。Logo 只放在纯色或低噪声背景上。

## 色彩系统

### 品牌原色

| 名称 | Hex | 用途 |
|---|---|---|
| Abyss 950 | `#07171C` | 顶部全局控制条、最深背景 |
| Abyss 900 | `#0B2027` | 次级导航、深色证据区 |
| Chart 600 | `#2D7889` | 主操作、链接、行情与图表主序列 |
| Chart 500 | `#4C9BAA` | 深色背景上的交互状态与载荷块 |
| Brass 600 | `#B97843` | PAPER、执行残余、关键但非告警的强调 |
| Brass 500 | `#CB8D54` | 深色背景上的压舱块和 PAPER 状态 |

### 中性色和状态色

| 名称 | Hex | 用途 |
|---|---|---|
| Mist 50 | `#F7F9F8` | 面板和表头浅色表面 |
| Mist 100 | `#EEF2F1` | 页面工作区背景 |
| Mist 200 | `#DBE4E2` | 分隔线和图表网格 |
| Ink | `#10272E` | 浅色背景主文字 |
| Signal green | `#3F8D72` | 已连接、完成、健康 |
| Signal red | `#C94F55` | 失败、陈旧、越界和需要处理的异常 |

颜色不单独承担状态含义。健康、等待和异常必须同时配合文字及点、菱形或边线等形状。黄铜不能用作普通主按钮；红色不能用于装饰或品牌强调。

## 字体

- IBM Plex Sans + 平台中文界面字体（PingFang SC / Hiragino Sans GB / Microsoft YaHei）：界面正文、中文页面标题、导航、状态和操作。标题使用 500–600 字重，避免过度展示化。
- Barlow Condensed：品牌字标、关键数值、交易所短名称。只用于短文本。
- IBM Plex Mono：价格、数量、时间、标识符和审计证据，不用于成段中文或中文状态文案。

正文最小 14px；密集表格与机器字段可使用 11–12px，但不能用于长段阅读。全大写只用于短状态和机器标签，并增加字距。

## 产品布局

顶部控制条分成两层：第一层显示品牌、PAPER/LIVE 边界、事件链路和全局工具；第二层按工作流显示主导航。数据工作区保持冷白、宽表格和低圆角。交易所不是五个品牌化一级入口，而是“市场与通道”中的业务维度。

稳定轴只出现在控制舱和任务详情。纸面阶段必须标注为“执行残余”；只有账户快照与成交对账可靠后才能改为“净敞口”。

## 组件和动效

- 面板采用 4px 圆角和轻阴影；表格、证据和状态行优先使用边线建立层级。
- 主按钮使用 Chart 600，危险操作使用 Signal red，普通次级操作保持中性描边。
- 所有可交互元素提供清晰的键盘焦点。
- 动效集中在稳定轴和链路状态变化，并遵守 `prefers-reduced-motion`。

## 文案

界面先说事实，再说影响和下一步。例如“行情已陈旧，任务暂停；恢复且未过截止时间后继续”，而不是“出现未知错误”。PAPER、LIVE、费用未计、未订阅和不支持等安全边界必须直接显示，禁止用模糊文案或演示数据掩盖。
